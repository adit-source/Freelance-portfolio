# Aditya Kumar — Freelance Data Analytics Portfolio

A responsive, static portfolio website focused on freelance services: Power BI dashboards, Excel reporting, SQL, and Python data analysis.

## Files
- `index.html` — content and page structure
- `style.css` — responsive visual design
- `script.js` — mobile navigation and current footer year

## Preview locally
Open `index.html` in a browser. No build step or package installation is required.

## Publish to GitHub Pages
1. Download and unzip this project.
2. Open your GitHub repository for the portfolio: https://github.com/adit-source/Portfolio
3. Back up the existing files before replacing anything.
4. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
5. Commit the changes to the branch configured for GitHub Pages (often `main`).
6. In **Settings → Pages**, confirm the deployment branch and folder.
7. Wait for GitHub Pages to deploy, then check https://adit-source.github.io/Portfolio/

## Before publishing
- Verify the contact email and LinkedIn profile in `index.html`.
- Confirm each project repository link is correct and public.
- Replace any project description if the underlying project changes.
- The dashboard artwork in the hero and project cards is illustrative UI artwork, not real client performance data.
- No client testimonials, client logos, or commercial results have been invented.
